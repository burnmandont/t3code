# Browse project files

Open **Files** in the right sidebar to browse the project filesystem. Folders start collapsed and
load when you open them, so large projects do not need to send their entire file list up front.

The browser includes hidden and Git-ignored files and folders, such as `.env`, generated assets,
and local build output. Sovereign hides only the repository's internal `.git` directory. In Git
repositories, file and folder colors and badges reflect their working-tree status; Git status does
not determine which files are visible.

Use the search field to find indexed project paths, or select the refresh button after files change
outside Sovereign.
